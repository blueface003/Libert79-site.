# LIBERT79 — version visuelle fidèle à la maquette

Cette version affiche la maquette créée comme visuel principal afin de conserver son apparence exacte. Des zones transparentes et cliquables ouvrent le lien partenaire; le bouton de code copie `LIBERT79`.

## Publier sur GitHub Pages
1. Décompressez le ZIP.
2. Téléversez **tous les fichiers** de ce dossier dans le dépôt GitHub `libert79-site` (notamment `index.html`, `style.css`, `script.js` et `maquette-libert79.png`).
3. Cliquez sur **Commit changes**.
4. Dans **Settings → Pages**, sélectionnez **Deploy from a branch**, branche `main`, dossier `/(root)`, puis **Save**.

Les photos et textes de la maquette sont illustratifs et ne constituent pas une confirmation d'offres officielles. Vérifiez les conditions applicables à chaque pays et les règles locales avant toute promotion. 18+; jouez de manière responsable.
